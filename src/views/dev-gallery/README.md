# views/dev-gallery

공용 컴포넌트를 한 화면에 늘어놓고 눈으로 확인하는 개발용 화면이다. **서비스 화면이 아니다.**

| 파일 | 설명 |
| --- | --- |
| `ui/dev-gallery-view.tsx` | 컴포넌트를 종류별로 배치한 화면 |
| `index.ts` | 공개 API |

## 라우트

`/dev` — `src/app/dev/page.tsx`

**프로덕션 빌드에서는 `notFound()`로 막힌다.** 디자인이 확정되고 실제 화면이 생기면 이 슬라이스를 지울지 판단한다.

## 공용 컴포넌트를 만들면 여기도 채운다

이 화면은 만들어 둔 공용 컴포넌트의 목록이기도 하다. 화면 작업을 하면서 컴포넌트만 만들고 갤러리를 갱신하지 않으면, 무엇이 이미 있는지 알 수 없어 같은 것을 다시 만들게 된다. 실제로 열두 개가 그렇게 빠져 있었다 (#75).

`shared/ui`와 `entities`의 `ui`에 컴포넌트를 추가하면 여기에도 구역을 하나 만들고, `dev-gallery-view.test.tsx`의 구역 목록에도 이름을 더한다.

**화면 하나를 통째로 차지하는 골격은 넣지 않는다.** 갤러리 안에 중첩하면 머리말과 하단 버튼 줄이 두 개씩 생긴다. "여기서 볼 수 없는 것" 구역에 어느 화면에서 볼 수 있는지 적는다.

Storybook을 두지 않기로 한 대신 두는 최소한의 확인 수단이다. 근거는 [library-convention](../../../docs/conventions/library-convention.md)의 "겪은 사례"를 본다.
