| 파일 | 설명 |
| --- | --- |
| `ui/add-pet-view.tsx` | 소개 문구와 사진 자리, 다음에 할게요 / 아이 추가하기 |
| `index.ts` | 공개 API |

## 라우트

`/mypage/pets/new` — 아이 고르기 줄의 "+"에서 온다.

**경로는 임시다.**

## 아직 없는 것

"아이 추가하기"는 잠겨 있다. 등록 뒤에 이어지는 화면이 시안에 없고, 정보 수정 화면은 이미 있는 아이를 고치는 곳이라 새 아이를 저장하지 못한다. 등록 전용 흐름이 정해지면 잇는다.
