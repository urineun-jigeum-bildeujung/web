## 짚어둘 것

**이름·생년월일은 화살표가 없다.** 시안은 다섯 줄 모두 화살표인데 고칠 화면이 없다(#64). 화면이 생기면 링크로 바꾼다.

**"내 아이들" 값은 아이 이름을 쉼표로 잇는다.** 시안 자리에는 닉네임 더미가 적혀 있어 PD 확인 대상이다(#194).

**배송지 항목은 한 화면이 새 배송지와 수정을 맡는다.** 어느 곳인지는 `?place=` 쿼리로 넘긴다. 배송지 입력 화면 자체는 #187에서 시안으로 옮긴다.
