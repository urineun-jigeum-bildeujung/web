# login

로그인. 소셜(카카오·구글)로만 들어온다.

- **라우트**: `/login` — `src/app/login/page.tsx`
- **조립**: 머리말과 소셜 링크 둘. `shared/ui`에서 가져오는 것이 없다
- **상태**: 없다. 소셜은 서버 상태 없이 주소 이동뿐이라 서버 컴포넌트다
- **참고**: UI 시안 기준(sign_001 로그인, `3574-80319`, #463)

| 파일 | 설명 |
| --- | --- |
| `ui/login-view.tsx` | 화면 조립 |
| `ui/login-view.test.tsx` | 소셜 링크가 가리키는 주소, 제공자 두 갈래, 폼이 없음 |
| `config/oauth.ts` | 소셜 로그인 시작 주소와 제공자 목록 |
| `index.ts` | 공개 API |

로고 파일은 `public/images/login/kakao.svg`(시안에서 받은 카카오 로고)다.

## 짚어둘 것

**소셜은 카카오·구글 둘이다.** 시안은 카카오·네이버를 그렸으나 인증 정책이 카카오·구글로 확정돼 네이버 자리에 구글을 뒀다. 구글 버튼은 시안이 없어 구글 브랜드 가이드(흰 바탕·테두리)대로 카카오 버튼과 같은 모양·크기로 맞췄다.

**아이디·비밀번호 폼은 없다.** 새 시안(`3574-80319`)에서 폼·자동로그인·아이디/비밀번호 찾기·회원가입 줄이 빠졌다(#463). 신규 회원은 소셜 콜백이 `needsSignup`으로 가입 화면에 보내므로 회원가입 링크 없이도 가입 경로가 남는다.

**버튼 글자는 `label-bold-16`이다.** 시안은 15px SemiBold인데 맞는 토큰이 없어 다른 주요 버튼(로그인·다음으로)과 같은 토큰을 쓴다(#463).

**카카오 글자는 모드와 무관한 검정이다.** 노란 바탕(`--kakao`, 카카오가 규정한 색)은 다크 모드에서도 그대로라 `text-text-label-static-black`을 쓴다.

**로고.** 카카오는 시안 SVG를 `next/image`로 `unoptimized` 그린다 — 18×18짜리라 최적화로 얻을 것이 없고 `/_next/image` 왕복만 는다(`TossPayLogo`와 같은 판단). 구글은 디자인 시스템 아이콘 세트 밖이라 react-icons 브랜드 글리프(`FcGoogle`)를 쓴다.

**"골라주개냥"은 검정이다.** 시안 텍스트가 검정이고 그 뒤의 분홍 사각형은 메모용 표시로 봤다. 브랜드색 강조가 의도라면 바꾼다(#184).

**소셜 버튼은 링크다.** 인증 제공자 화면으로 리다이렉트되는 흐름이라 fetch로는 따라갈 수 없다. 브라우저를 통째로 보내는 이동이므로 `button`이 아니라 `a`를 쓴다 — 새 탭으로 열기·주소 복사 같은 기본 동작이 따라오고 스크린 리더도 이동으로 읽는다.

**시작 주소만 `/api/v1`이 아니다.** 게이트웨이가 일반 API(`/api/v1/**`)와 별개로 `/api/auth/oauth2/authorization/**`를 Spring Security OAuth2 클라이언트로 보낸다. `NEXT_PUBLIC_API_BASE_URL`에서 파생할 수 없어 `NEXT_PUBLIC_OAUTH_BASE_URL`을 따로 받는다.
