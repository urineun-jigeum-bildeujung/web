# login

로그인. 아이디·비밀번호로 들어오거나 소셜로 들어온다.

- **라우트**: `/login` — `src/app/login/page.tsx`
- **조립**: `shared/ui`의 `form-field` · `checkbox-row` · `button`
- **상태**: 입력값과 자동로그인 여부 모두 화면 안 상태. 실제 인증은 미연동
- **참고**: 와이어프레임 기준(sign_001)

| 파일 | 설명 |
| --- | --- |
| `ui/login-view.tsx` | 화면 조립 |
| `index.ts` | 공개 API |

## 짚어둘 것

**소셜은 카카오·구글 둘이다.** 시안에는 넷(카카오·네이버·애플·구글)이 그려져 있고 "MVP는 카카오·네이버"라는 메모가 붙어 있으나, 카카오·구글로 확정돼 그에 맞췄다. 시안이 아직 갱신되지 않은 상태다.

**브랜드 색은 아이콘이 들고 있다.** 배경이 필요한 카카오만 `--kakao` 토큰을 `globals.css`에 뒀다. 카카오가 규정한 색이라 우리 팔레트와 무관하게 고정이다.

**아이디·비밀번호 찾기는 링크를 걸지 않았다.** 갈 화면이 시안에 아직 없다. 링크를 걸면 404가 되고 버튼으로 두면 눌러도 아무 일이 없어 고장으로 읽힌다 — `ListRowStatic`과 같은 판단이다. 화면이 생기면 링크로 바꾼다.

## 아직 정하지 않은 것

**실제 인증은 붙이지 않았다.** 자사 로그인도 소셜도 화면만 있다. 백엔드 인증 방식과 소셜 연동 방식이 확정되어야 한다.
