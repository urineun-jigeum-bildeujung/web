## 라우트

`/mypage/reviews/[reviewId]` — `src/app/mypage/reviews/[reviewId]/page.tsx`. 나의 상품 후기 → 작성한 리뷰에서 이어진다.

## 시안과 같은 것

- X로 닫는 헤더(943-15503). 시안의 오른쪽 장바구니 아이콘은 시안 자체가 숨김(opacity 0)이라 두지 않는다.
- 정사각 사진(943-15512)과 아래 점(6px, 간격 4px). 시안에 화살표가 없어 옆으로 밀어 넘긴다(스크롤 스냅). **점은 표시용이고 누르지 않는다** — 6px 점을 10px 간격으로 두면 터치 영역이 겹쳐 엉뚱한 장으로 가고, 44px씩 벌리면 시안 간격이 깨진다(#365 리뷰). 키보드에는 초점이 올 때만 보이는 이전·다음 버튼(44px)을 둔다.
- 후기 묶음(943-15521): 좌우 20px, 줄 사이 8px. 닉네임 → 별점(20px)과 날짜 → 칩 → 글. 글자·칩 값은 같은 시안 계열을 먼저 옮긴 `entities/review/ui/review-card.tsx`와 같게 맞췄다(15px 토큰이 없어 닉네임 `label-bold-14`, 날짜 `label-medium-11`, 칩 `label-medium-12`, 글 `body-medium-14`).

## 시안과 다른 것

- 제목은 "사진 리뷰"가 아니라 "리뷰 상세"다. 사진 없는 후기도 이 화면으로 온다. 사진이 없으면 사진 자리를 통째로 비운다.
- "[옵션] 90정 1병" 줄은 응답에 옵션이 없어 두지 않는다. "재구매 2회" 칩도 응답에 없다.
- 칩에 반응(좋았던 점·아쉬운 점, "기호성 좋음" 꼴)을 아이 프로필·사용 기간 뒤에 덧붙인다. 이 서비스가 내세우는 근거라 버리지 않았다.
- 신고하기·도움돼요 줄(943-15543)과 하단 찜·장바구니·바로 구매 줄(943-15550)은 **props로 켠다.** 마이페이지의 내 리뷰(`/mypage/reviews/[reviewId]`)는 둘 다 끄고, 나중에 상품 쪽에서 남의 리뷰를 볼 때 `showReactions`·`showPurchaseBar`를 켠다. 켰을 때의 모양과 동작은 `ReviewCard`·사진 리뷰 뷰어와 같다 — 신고 접수·도움돼요·찜 API가 아직 없어 화면 안에서만 움직이고, 응답에 `likeCount`가 없어 내가 누른 것만 센다.

## 아이 칩은 아이마다, 닉네임은 내 정보에서

응답의 `pets`(쓸 당시 스냅샷: 이름·나이·종·체구)가 여러 마리라 칩을 아이마다 그린다(#391). 스냅샷에 품종명·몸무게가 없어 내 아이면 `useQueryPetDetail`로 받아 "말티즈 · 8세 · 4kg", 못 받으면(남의 아이·지운 아이) "코코 · 8세"다. 닉네임은 응답에 없어(백엔드 요청 중) 마이페이지 아래라 내 정보에서 채운다. **응답의 `isMine`으로 가리지 않는다** — 새로고침 직후엔 액세스 토큰이 아직 메모리에 없어 상세 조회가 인증 없이 나가고 `isMine`이 `false`로 온다. 별점은 저장값 그대로 0.5 단위이고 `Rating`이 반 개를 그린다.

## 상태 넷

받는 중은 사진 자리 크기의 스켈레톤, `REVIEW_404_NOT_FOUND`는 "찾을 수 없어요"(다시 시도 없음 — 다시 보내도 같다), 그 밖의 실패는 다시 시도, 성공은 내용이다. `matchScore`는 백엔드가 아직 항상 `null`이라 그리지 않는다.
