# views/select-breed

아이 정보를 고칠 때 품종을 고르는 화면. 와이어프레임 `onbo_013_품종선택`과 같은 화면이다.

| 파일 | 설명 |
| --- | --- |
| `ui/select-breed-view.tsx` | 품종 목록과 고르기 |
| `ui/select-breed-view.test.tsx` | 지금 값이 미리 골라지는지, 종까지 함께 돌려주는지 본다 |
| `index.ts` | 공개 API |

## 라우트

```text
/mypage/pets/breed?value=<지금 품종>
```

## 온보딩과 나눈 이유

온보딩은 한 라우트(`/onboarding`) 안에서 단계를 쿼리로 넘기므로 품종 고르기도 그 안의 한 단계다. 정보 수정은 `/mypage/pets/basic`에서 따로 들어오기 때문에 라우트가 필요하다.

목록을 그리는 `BreedPicker`는 `entities/pet`에 있어 양쪽이 같은 것을 쓴다. 고른 품종이 어느 종의 것인지 되찾는 `findSpecies`도 두 곳에서 쓰게 되어 `entities/pet`으로 올렸다.

## 고른 값을 돌려주는 방법

`/mypage/pets/basic?breed=<품종>&species=<종>`으로 넘긴다. 비교 화면에서 상품을 고를 때와 같은 방식이다. 새로고침·뒤로가기에서 남아야 하는 값이고, 라우터 구조가 바뀌어도 이 규약은 그대로 쓸 수 있다.

**"선택 완료"를 눌러야 넘어간다.** 시안에 돌아가기와 선택 완료 두 버튼이 있어 고르다 취소할 수 있어야 한다.
