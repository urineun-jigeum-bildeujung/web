# views/edit-address

| 파일 | 설명 |
| --- | --- |
| `ui/edit-address-view.tsx` | 배송지 추가·수정 |

## 라우트

`/mypage/address/new` — **경로는 임시다.** 페이지·라우터 구조는 다른 팀원이 작업 중이며 그 결과로 교체한다.
