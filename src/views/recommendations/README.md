# views/recommendations

고른 아이의 건강 고민에 맞는 상품을 모아 보여준다. 와이어프레임 `reco_001`·`reco_001_변경`에 대응한다.

| 파일 | 설명 |
| --- | --- |
| `ui/recommendations-view.tsx` | 상품 둘러보기 (`reco_001`) |
| `ui/recommendations-view.test.tsx` | 적합도가 문장으로도 읽히는지, 아이를 고를 수 있는지 본다 |
| `index.ts` | 공개 API |

## 라우트

```text
/recommendations?pet=<아이 id>&concern=<건강 고민>
```

어느 아이 기준인지와 어떤 고민으로 걸렀는지를 주소에 남긴다. 상품 상세로 갔다 돌아와도 조건이 유지되어야 한다.

## 이 화면이 하는 말

**"보호자님이 알려주신 건강 고민을 바탕으로 추천해요"**를 화면에 적는다. 별점·인기순 나열과 갈라지는 지점이라, 무엇을 근거로 골랐는지 보이지 않으면 이 화면의 의미가 없다.

적합도는 숫자만 두지 않고 구간 문구를 함께 노출한다. 92라는 값만으로는 높은지 낮은지 판단을 사용자에게 떠넘기게 된다.

## 아직 없는 것

- 적합도·추천 결과가 목데이터다. AI 응답 형식이 정해지면 교체한다. 점수 단위(0~1인지 0~100인지)도 미정이라 지금은 0~100으로 뒀다
- 정렬은 시안에 "맞춤 추천"만 보인다. 나머지 기준은 PD 확인 뒤에 늘린다
- 건강 고민 칩(관절·알러지·구강관리)이 고정이다. 실제로는 아이가 등록한 고민에서 나와야 한다
- 찜이 서버에 남지 않아 새로고침하면 처음으로 돌아간다
