## 짚어둘 것

**남은 시간이 다 되면 목록도 함께 사라진다.** `Countdown`의 `onEnd`로 알려 받아 비워짐 화면으로 바꾼다. 세는 것만 멈추면 살 수 없는 상품이 그대로 남는다.

**진행중 탭의 썸네일·텍스트를 누르면 상품 상세(`/products/[id]`)로 간다.** 다른 상품 목록 화면(검색 결과·맞춤 추천 등)과 같은 동작이다. 담기 버튼은 링크 안에 두면 "링크 속 버튼"이 되어 눌리지 않으므로, `product-grid-card`의 `imageAction`과 같은 방식으로 링크 바깥에 절대 위치로 뺐다. 딜 id가 아직 실제 상품 id가 아니라 상세 페이지엔 다른 화면과 같은 목업 상품이 뜬다. 오픈 예정 탭은 애초에 누를 버튼이 없어 카드 전체를 그대로 링크로 바꾸면 되는데, 이번엔 진행중 탭만 요청받아 그대로 뒀다.

**가격은 `Price` 컴포넌트를 쓰지 않는다.** 시안의 줄 순서(정가 취소선이 위, 할인율+최종가가 아래)가 `Price`의 내부 순서(할인율·최종가·정가 순으로 한 줄)와 달라, `product-grid-card`처럼 `calcDiscountRate`·`formatWon` 유틸만 가져와 화면에 맞게 직접 그린다.

**목록과 옵션 시트가 같은 목 데이터를 본다(`LIVE_DEALS`).** 시안 원본은 같은 상품인데도 목록(24,000원)과 옵션 시트(21,000원) 가격이 서로 달랐다 — 두 Figma 프레임을 각각 옮기면서 생긴 목데이터 단계의 불일치로 보인다. 코드에 가격을 두 번 두지 않고 한 곳만 참조하게 해 이 문제를 원천적으로 피했다. 실제 API가 붙으면 가격은 서버가 주는 값 하나로 통일되므로 별도 확인이 필요한 문제는 아니다.

**담기 바텀시트(`entities/product`의 `ProductOptionSheet`)도 이번에 시안대로 다시 그렸다.** 지금은 이 화면만 쓰는 컴포넌트라 다른 화면에는 영향이 없다.

**화면 맨 아래 "[개발용]" 버튼은 시안에 없다.** 진행 중인 딜의 실제 잔여 시간이 11시간대라 빈 화면을 보려면 오래 기다려야 해서, QA가 빈 상태·있는 상태를 즉시 오갈 수 있게 임시로 둔 버튼이다. `NODE_ENV`로 막아 둬 운영 빌드에는 나가지 않는다.

**오픈 알림 신청 후엔 버튼 문구만 "신청됨"으로 바뀐다.** 카운트다운은 신청 여부와 무관하게 계속 보여준다 — 신청 후에도 취소할 수 있어 "신청했으니 초를 지켜볼 이유가 없다"는 원래 전제가 깨졌다. 다시 누르면 신청이 취소되고 원래 버튼으로 돌아간다. 이 "신청됨" 상태 자체의 문구·색 시안은 아직 개별 확인 전이다.

**담기 아이콘은 세트의 `bag`이 아니라 `cart`를 쓴다.** `bag`은 꽉 찬 검정 실루엣이라 시안의 얇은 선 스타일과 달랐다. `cart`는 이미 머리말에서 같은 선 스타일로 쓰고 있어 그대로 재사용했다.

**공용 스낵바(`shared/ui/snackbar`)는 결국 손대지 않는 게 맞았다.** 시안(1905-32403 전체 화면 기준, 스낵바 인스턴스가 x=20·width=353)을 보면 스낵바는 좌우 20px 여백을 둔 고정 폭 바이고 문구는 왼쪽 정렬이다 — 독립 컴포넌트만 내보낸 화면(1905-32431)이 문구 크기에 맞춰 잘려 보여서 한동안 "문구 길이만큼만 차지하는 알약"으로 착각하고 폭을 줄이거나 가운데 정렬을 넣는 시도를 몇 차례 했는데, 전부 시안과 달랐다. 원래 `SNACKBAR_CLASS`(`w-[calc(100vw-40px)] max-w-88.25`)가 이미 정확했다 — `max-w-88.25`(353px)가 넓은 창에서도 폭을 그 이상 못 늘어나게 잡아 주고 있었다.

**아이콘 색은 셋 다 다른 토큰이다.** 목록 담기 아이콘은 `icon-fill-secondary`(#565D6D), 담긴 상태 체크 아이콘은 `icon-fill-default`(#2A3038), "오픈 알림 신청하기"의 종 아이콘은 `icon-stroke-tertiary`(#868B94) — 텍스트 색(진하게)과는 별개로 아이콘만 옅다. Figma 데브 모드의 실제 CSS 값으로 확인했다.

## 아직 확인이 끝나지 않은 것

시안과 다르게 남겨두었거나 시안 자체가 불명확해 PD팀 확인이 필요한 항목은 로컬 QA 문서에 정리했다. 빈 화면의 "상품 둘러보기" 버튼 유무, 헤더 장바구니 개수 배지, 바텀시트 상품명(15px SemiBold을 14px Bold로 근사), 바텀시트 손잡이 위 여백(공용 `Drawer` 손잡이가 시안보다 짧아 임의 보정), 빈 화면의 아이콘 색·제목 굵기가 다른 화면들의 빈 상태 기본값과 다른 것(의도된 차이인지 확인 필요), **"오픈 알림 신청됨" 상태 문구·모양의 시안 미확인**이 그 대상이다.
