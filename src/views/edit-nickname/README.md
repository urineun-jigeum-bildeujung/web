## 짚어둘 것

**지금 닉네임을 채운 채로 연다**(QA No.143, #594). 시안(`1482-28361`)은 입력칸을 비워 두고 회색 글자로만 보이는데, 그러면 비활성처럼 보이고 한 글자만 고치려 해도 전부 다시 쳐야 했다. 들어오자마자 고칠 수 있게 커서를 두고(`autoFocus`) 문자 키패드(`inputMode="text"`)를 띄운다.

**받은 값을 상태에 옮겨 담지 않는다.** 조회가 화면보다 늦게 도착하므로 `useState` 초기값으로 넣으면 빈 칸이 된다. 친 값만 상태로 들고, 손대기 전에는 받은 닉네임을 보인다 — 받기 전에 친 값은 도착한 닉네임에 덮이지 않는다.

**손대지 않은 값은 저장할 수 없다.** 아이 정보·배송지 수정은 바꾼 것이 없어도 저장이 열려 있지만, 닉네임은 서버가 중복을 검사한다(`MEMBER_409_ALREADY_HAVE_NICKNAME`). 채운 채로 열리면서 새로 생긴 "그대로 저장"이 자기 닉네임을 "사용 중"으로 거절당할 수 있어 막는다. 채우기 전에도 빈 칸이라 저장이 막혀 있었으니 동작은 같다.

**닉네임만 보낸다.** `PATCH /members/me`는 전 필드가 선택이라, 이름·생년월일까지 실으면 이 화면이 고치지도 않은 값을 덮어쓴다 (#266).
