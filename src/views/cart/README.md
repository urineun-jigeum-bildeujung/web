# views/cart

담아 둔 상품을 고르고 수량을 바꾸거나 빼는 화면. 와이어프레임 `cart_001`과 그 두 상태에 대응한다.

| 파일 | 설명 |
| --- | --- |
| `ui/cart-view.tsx` | 장바구니. 옵션 변경 시트와 삭제 확인창을 함께 가진다 (`cart_001`) |
| `ui/cart-view.test.tsx` | 무엇이 합계에 들어가는지, 고른 것이 없을 때 결제로 가지 못하는지 본다 |
| `index.ts` | 공개 API |

## 라우트

```text
/cart  장바구니
```

**경로는 임시다.** 옵션 변경과 삭제 확인은 같은 화면의 상태라 라우트를 나누지 않았다. 뒤로 가기로 시트만 닫히는 흐름이 필요해지면 그때 쿼리로 올린다.

## 합계를 세는 규칙

고른 상품만 더한다. 하나도 고르지 않으면 배송비도 물리지 않고 결제하기가 잠긴다. 배송비는 3,000원 고정으로 두었다 — 무료배송 기준이 정해지면 바뀐다.

## 아직 없는 것

- 목록이 목업이다. 담기·수량 변경·빼기가 서버에 남지 않아 새로고침하면 처음으로 돌아간다
- 상품 옵션 목록이 세 개로 고정이다. 실제로는 상품마다 다르다
- 결제하기가 `/payment`로 가지만 고른 상품이 함께 넘어가지 않는다. 화면 간 전달은 라우터 구조가 정해진 뒤에 붙인다
- 비어 있을 때의 화면은 `EmptyState`로 그려 두었으나 시안이 없다
