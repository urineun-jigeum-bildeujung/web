# views/pet-profile

반려동물의 정보와 그 아이가 먹은 제품을 관리하는 화면. 와이어프레임 `mypa_021`·`mypa_021_상품클릭시`에 대응한다.

| 파일 | 설명 |
| --- | --- |
| `ui/pet-profile-view.tsx` | 두 탭과 아이 고르기 줄을 조립한다 |
| `index.ts` | 공개 API |

## 라우트

`/mypage/pets` — `src/app/mypage/pets/page.tsx`

**경로는 임시다.** 진입점은 마이페이지 반려동물 줄과 내 정보 "내 아이들" 두 곳이다.

## 탭을 주소창에 두는 이유

`?tab=products`로 다룬다. 제품을 눌러 상세로 갔다 돌아왔을 때 보던 탭이 남아야 하기 때문이다. 나의 후기 화면도 같은 방식이다.

## 아직 없는 것

- 아이를 바꿔도 화면 내용은 그대로다. 아이별 데이터는 API 계약이 정해진 뒤에 붙인다
- 제품 후기의 "수정하기"는 갈 화면이 없어 아직 잇지 않았다
