# widgets/cart-link

헤더의 장바구니 링크. 담아 둔 가짓수를 아이콘 오른쪽 위 뱃지로 붙인다(#470).

| 파일 | 설명 |
| --- | --- |
| `ui/cart-link.tsx` | `/cart`로 가는 장바구니 링크. 담은 줄이 있으면 18px 브랜드색 뱃지에 그 수를 보이고(100부터 `99+`), 링크 이름을 "장바구니에 N개"로 바꾼다. 없으면 뱃지 없이 "장바구니" |
| `ui/cart-link.test.tsx` | 담은 것이 있을 때만 뱃지가 붙는지, 링크 이름에 수가 실리는지, 로그인 여부를 조회에 넘기는지 |
| `index.ts` | 공개 API |

## 왜 위젯인가

헤더 여섯 곳(메인·상품 상세·찜·비교·타임딜·마이페이지)이 장바구니 링크를 각자 그렸고, 메인과 상품 상세는 뱃지를 "5"로 박아 두었다. 수는 서버 상태라 훅이 필요하고, `entities/cart`의 `useQueryCartCount`를 여러 화면이 같은 모양으로 쓰므로 알림 종(`widgets/notification-bell`)과 같은 자리에 둔다. 맞춤 추천 헤더에는 아이콘이 없었다(QA 1차 2번).

**수는 줄 수다.** 같은 상품을 셋 담아도 1이다. 로그인하지 않았으면 장바구니를 부르지 않고 뱃지도 없다.

## 어디에 있나

메인·상품 상세·찜·비교·타임딜·마이페이지·맞춤 추천 헤더. 링크 자리 모양이 다른 헤더(타임딜 44px 터치 자리, 마이페이지 44px 버튼)는 `className`으로 넘긴다.

**누르는 자리.** 기본은 보이는 28px에 가로 4px·세로 8px을 안 보이게 넓힌 36×44px이다. 가로는 헤더 아이콘 간격 9px의 절반이 안 되게 둬 옆 아이콘과 겹치지 않는다. 전에 헤더들이 쓰던 `after:-inset-x-1.125`(4.5px)는 0.25 단위가 아니라 Tailwind가 CSS를 만들지 않아, 실제로는 보이는 28px만 눌렸다(#470 리뷰). 알림 종·메인·찜의 검색도 같이 고쳤다.
