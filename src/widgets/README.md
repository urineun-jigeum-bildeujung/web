# widgets 레이어

여러 화면에서 재사용되는, 독립적으로 동작하는 큰 UI 블록이다.

## 담는 것

- 헤더, 바텀 내비게이션, 사이드바
- `features`와 `entities`를 조합해 하나의 완결된 블록을 이루는 것 (예: 상품 목록 섹션, 대시보드 요약 카드)

## 담지 않는 것

- 한 화면에서만 쓰는 구성 → `views`
- 단일 사용자 행동 → `features`
- 도메인 모델 하나의 표현 → `entities`
- 버튼·인풋 같은 프리미티브 → `shared/ui`

## 판단 기준

"이 블록을 다른 화면에 그대로 옮겨도 동작하는가"를 묻는다. 그렇다면 `widget`이고, 아니면 `views`에 둔다.

## 의존 방향

`features` · `entities` · `shared`를 import할 수 있다. `views`와 `app`은 import하지 않는다.

같은 레이어의 다른 widget도 import하지 않는다.
